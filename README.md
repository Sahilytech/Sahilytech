```text
                 ╭──────────────────────╮
                 │       N U B I        │
                 │  PERSONAL AI LAYER   │
                 ╰──────────┬───────────╯
                            │
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
   MEMORY CORE         VOICE LAYER        AUTOMATION
        │                   │                   │
        └───────────────────┼───────────────────┘
                            ▼
                    LOCAL-FIRST SYSTEM
```

**Nubi** is the direction behind several experiments: an assistant that can live on the desktop, understand context, interact through voice, remember useful information locally and act as a bridge between the user and their computer.
